# 大清天朵二期社區 AI 管理助手 (Daqing Tianduo Phase 2 Community AI Assistant)

專為「大清天朵二期社區」量身打造的專屬智慧管理助手系統。遵循社區管理委員會規約、固德物業作業標準手冊 (SOP) 以及公寓大廈管理條例規範。

---

## 🚀 執行方式 (How to Run)

本專案支援 **GitHub 線上免安裝即開即用** 與 **本地一鍵雙擊執行** 兩種模式：

### 模式一：GitHub 線上直接執行（免安裝、開箱即用）
本專案已配置 GitHub Actions 自動發布至 **GitHub Pages**。
任何住戶、管委會委員或物業人員，只要在瀏覽器中開啟下列網址即可立即操作完整功能（支援在線 AI 交談、規約比對、氣象連線、工單派單與簽核）：

👉 **[立即體驗 GitHub Pages 線上版](https://fruit8428.github.io/------/)** *(於 GitHub 專案 Settings > Pages 開啟後自動生效)*

> 💡 **離線/雲端獨立引擎支援**：在 GitHub Pages 或純靜態環境下，系統會自動切換為「雲端免伺服器模式」，所有資料將安全儲存於瀏覽器本地空間 (`localStorage`)，無須任何後端伺服器即可完整執行所有情境！

---

### 模式二：本地一鍵執行檔（Local Executables）

在 GitHub 取得專案原始碼後，不同作業系統均提供專屬的「一鍵啟動檔」：

#### 🍏 macOS 使用者（推薦）
在訪達 (Finder) 中直接**雙擊**專案目錄下的：
```bash
start.command
```
- 腳本將自動檢驗 Python 3 環境、在背景啟動伺服器，並自動為您開啟預設瀏覽器前往 `http://127.0.0.1:8080`。

#### 🪟 Windows 使用者
在檔案總管中直接**雙擊**：
```batch
run.bat
```
- 自動啟動本機伺服器並彈出瀏覽器。

#### 🐧 Linux / macOS 終端機使用者
在終端機直接執行：
```bash
./run.sh
# 或手動啟動：
python3 server.py
```
伺服器啟動後，請於瀏覽器開啟：`http://127.0.0.1:8080`

## 📋 系統身分權限與 5 大核心功能 (Skills)

系統嚴格貫徹 **保護隱私**、**客觀中立** 與 **資訊精煉** 三大基本準則，提供三大身分一鍵切換視角：
1. **住戶 (Resident)**：個人管理費繳納查詢（金流隱碼保護）、異常拍照回報、社區公告查詢。
2. **固德物業人員 (Gude Property)**：派單工單中心、月結零用金報表提交、全社區繳費清單與催繳管理。
3. **管委會委員 (Committee)**：零用金法定三委員多重簽核、歷屆會議決議檢索、防汛實兵操演督導。

### 🌟 5 大技能模組 (Skills & Workflows)

| 技能模組 | 觸發條件與功能特性 |
| :--- | :--- |
| **Skill 1: 公寓大廈管理條例與決議邏輯檢核** | 檢索歷屆區權會大會決議與社區公約，針對常見爭議（**走廊放置薄型鞋櫃案**、**地下室充電樁安裝規範**、**冷氣室外機外牆規範**、**防水閘門定期操演規約**）自動輸出標準四大區塊：<br>① 相關規約條文 ② 歷史決策慣例 ③ 潛在邏輯矛盾或衝突點 ④ 客觀中立處理建議。 |
| **Skill 2: 影像辨識與自動派單** | 接收住戶 LINE 傳送或 CCTV Webhook 自動截圖，Vision AI 即時分析圖片並標籤分類（**垃圾棄置 Trash**、**遺失物 Lost Item**、**設施損壞 Damage**、**CCTV違規 Other**），自動派發至清潔組、管理中心或機電修繕組。 |
| **Skill 3: 社區財務自動銷帳** | 解析銀行入帳 Email/通知信中的【金額】與【帳號末5碼】，自動比對戶別並更新為已繳費狀態，生成防偽電子收據推播給該住戶（自動隱碼保護）。 |
| **Skill 4: 零用金多重簽核流** | 固德物業申報每月零用金（上限 10 萬元），提供**資訊精煉摘要**（總支出、剩餘額度、最大筆開銷 TOP 3）；**主任委員**、**財務委員**、**監察委員** 3 人獨立線上審核，集滿 3 票同意自動生成「零用金結算核准書」PDF / 列印憑證。 |
| **Skill 5: 防汛預警與防水閘門定期操演** | **年度例行排程**：每年 5 月 1 日系統自動推播防汛提醒，要求物業於 5/20 前完成防水閘門軌道潤滑、橡膠止水條密封檢驗、50包沙包盤點與 15 分鐘內組裝閉合實兵操演。<br>**中央氣象局 (CWA) 豪大雨連線**：即時介接台北市豪大雨特報，60 秒內主動緊急推播至管委會與現場管理員，自動啟動 4 項一級防汛應變 SOP。 |

## 📂 專案檔案結構 (Project Structure)

```text

├── .github/
│   └── workflows/
│       └── deploy.yml          # GitHub Actions 自動部屬 GitHub Pages 工作流

├── .gitignore                  # Git 版本控制排除清單
└── README.md                   # 專案操作說明文檔
```
